# Database operations corpus v1

The JSONL contains project-authored summaries checked against the linked PostgreSQL
18 manual pages on 2026-11-26. Each row names its source, publisher, version,
and license. The [PostgreSQL License](https://www.postgresql.org/about/licence/)
covers the upstream documentation. The corpus contains summaries in original
wording and links to the source pages. PostgreSQL is the subject of these notes.
Oracle Cloud stores and searches their embeddings.
